01 / 这是什么

GitHub Pages 到底是个啥？

一句话：它是 GitHub 提供的一个免费服务，能把你的网页文件变成一个真正能访问的网站。

你写好的 网页文件（比如 index.html），平时只能在自己电脑上双击打开，别人看不到。

把这些文件传到 GitHub 上，打开开关，GitHub 就会自动给你一个网址，例如 https://你的用户名.github.io，然后全世界任何人都能用浏览器打开它。

💡 打个比方：你做了一张海报，GitHub Pages 就是那面免费、24 小时开放、全球可见的「公告墙」，帮你把海报贴出去。

03 / 怎么用

三步，把它搬上网

全程在网页上点点鼠标就行，不需要懂命令行。点开每一步看看 👇

1

注册 GitHub，新建一个仓库

›

打开 github.com 注册一个免费账号（已有就直接登录）。

点右上角 + → New repository 新建一个「仓库」（Repository，可以理解成一个项目文件夹）。

想要最干净的网址，就把仓库名起成 你的用户名.github.io（比如用户名是 amy，就叫 amy.github.io）。记得勾选 Public。

2

把网页文件传上去

›

进入刚建好的仓库，点 Add file → Upload files。

把你的网页文件（至少要有一个 index.html）直接拖进去，然后点下方的 Commit changes 保存。

首页文件必须叫 index.html —— 这是网站的「大门」，浏览器默认先找它。

3

打开 Pages 开关

›

在仓库里点 Settings → 左侧菜单 Pages。

在 Branch 处选 main，文件夹保持 / (root)，点 Save。

等 1～2 分钟，刷新页面，上方会出现你的网址 https://用户名.github.io —— 点开，你的网站上线啦！🎉

05 / 常见问题

新手最常问的

Q：真的不要钱吗？个人公开项目完全免费，GitHub 不收托管费、不收流量费，足够日常使用。
Q：网址多久才能打开？第一次开启后通常等 1～5 分钟。之后每次更新文件，几十秒到几分钟内自动刷新。
Q：能放视频、做后台、连数据库吗？它只托管「静态网页」（HTML/CSS/JS、图片等）。需要后端逻辑或数据库的功能它做不了，但纯前端页面绰绰有余。
Q：首页文件一定要叫 index.html 吗？是的，根目录的首页请命名为 index.html，否则打开网址会显示 404。
Q：可以用自己的域名吗？可以。Pages 设置里有 Custom domain，绑定你买的域名即可，进阶玩法，暂时不绑也完全没问题。
